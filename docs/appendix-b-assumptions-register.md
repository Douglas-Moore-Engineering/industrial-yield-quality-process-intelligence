# Appendix B — Assumptions Register

| ID | Assumption |
|---|---|
| A-001 | Telemetry exists at a useful resolution for the selected event horizon |
| A-002 | Production runs/orders can be temporally identified |
| A-003 | Quality results can be related to product/run/material context |
| A-004 | Some material genealogy exists or can be reconstructed |
| A-005 | Historical quality/scrap dispositions are available |
| A-006 | Machine states/events are recorded for at least the pilot line |
| A-007 | Maintenance records can be linked to asset/component identities |
| A-008 | Existing control alarms/interlocks remain authoritative |
| A-009 | AI initially operates only as advisory intelligence |
| A-010 | Plant operation remains independent of AI availability |
| A-011 | Historical data quality and clock alignment will vary |
| A-012 | Different lines/plants may require local calibration |
| A-013 | Not all quality/scrap labels are reliable |
| A-014 | Engineering domain review is available for causal/physical validation |
| A-015 | No business outcome target is claimed until baseline data is measured |
