10. Release pipeline
11. Observability / SLO response
12. Cloud-agnostic deployment topology

## Diagram standard
- 8.5 × 11 portrait when rendered for documents
- white background
- consistent swim lanes
- curved connectors
- exclusive merges for mutually exclusive paths
- parallel gateways only when work is truly concurrent
- no synchronization bars for approve/modify/reject branches
