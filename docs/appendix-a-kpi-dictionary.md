# Appendix A — KPI Dictionary

| KPI | Definition |
|---|---|
| First Pass Yield | Conforming output accepted without rework / total output |
| Material Yield | Good material output / material input |
| Scrap Rate | Scrap quantity / total processed material |
| Cost of Poor Quality | Scrap + rework + hold + inspection + associated losses |
| Warning Horizon | Time between useful system warning and irreversible quality outcome |
| False Alerts / Shift | Operational alert burden for non-actionable predictions |
| Calibration Error | Difference between predicted probability and observed outcome rate |
| Time to Trace | Elapsed time to identify upstream/downstream affected genealogy |
| Time to Diagnose | Elapsed time from event recognition to accepted root-cause hypothesis |
| Intervention Success | Fraction of approved recommendations followed by desired stabilized outcome |
| Abstention Rate | Fraction of cases where system explicitly declines to predict/recommend |
| Data Freshness | Age of latest acceptable source event |
| Genealogy Completeness | Percent of product entities with complete required upstream lineage |
